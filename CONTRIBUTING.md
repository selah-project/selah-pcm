# To contribute for di Naija Pidgin version of Selah

Thank you for helping dis version to dey more correct, more clear,
and more natural. You no need to be expert: talk wetin you see,
give di ground wey you get, and separate wetin you sure of from
wetin you dey suggest.

## To report problem or ask for correction

- Open **issue** if di text need discussion, if e get more than one
  way to read am, or if you no sure how di alignment record go
  change.
- Open **pull request** if di error and im correct replacement dey
  clear.
- For software fault, or matter of security/account/privacy, use
  [Selah Support](https://selahproject.com/support).

## Wetin to include

Di book, chapter, verse, di Hebrew piece wey concern am; di present
text; di text wey you dey propose; di reason for di change; and di
ground from dictionary, grammar, context or publishing. Talk too if
you be Naija speaker and if you dey read Hebrew direct.

## Rules for changing di record

Di files dey for `<book>/<chapter>/<verse>.json`.

- Change `translation` and di `gloss` of di pieces wey concern am
  together, if both of dem dey involved.
- No touch `book`, `chapter`, `verse`, `ref`, di Hebrew `surface`
  values, or di order and number of di pieces — alignment error na
  di most costly error of all.
- Follow **di Name table**: יהוה → **Yahweh**; אלהים → **Elohim**;
  אדני → **Adonai**; שדי → **Shaddai**; שאול → **Sheol**; חסד →
  **chesed**. **GOD**, **LORD**, **Jehovah**, **Oga** and **Baba
  God** for di Name seat — dem dey rejected.
- Keep di **⟨את⟩** marker and di ⟨bracket⟩ additions; no remove dem
  quiet-quiet.
- Spelling standard, one spelling per word: di, dey, don, bin, go,
  wey, make, am, dem, una, wetin, sey.

## Standards

Hebrew first. If two readings both dey stand, explain di
difference — no present preference like certainty. No copy modern
translations wey get copyright.

## Work wey AI don help

Talk am if you use language model or machine translation well-well
— together wit your own human review. No send plenty rewritten text
wey nobody don check. Every word wey you propose na di contributor
own responsibility.

## License, credit and review

By contributing you dey talk sey you get di right to do am and you
gree sey wetin enter go dey distributed under
[CC BY-SA 4.0](LICENSE.md). Git history dey keep open record and
credit. Di team wey dey maintain go compare di proposal wit di
Hebrew, di rules, di sources and di alignment — dem fit accept am,
work am out wit you, wait for more ground, or reject am wit reason.
Criticize di text, no be di person.
